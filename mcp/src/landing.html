How it works

Record. The app captures periodic screenshots with ScreenCaptureKit, skipping idle stretches and apps you've blocked. Everything lands in a SQLite database on your Mac.

Distill. An LLM you choose — Gemini, Claude Code, Codex, or a local model — batches the captures into timeline cards: what you did, when, in which category, with which apps. A daily recap is generated each morning.

Serve. Every few hours the app pushes day snapshots to a Postgres you own. Your agents read it back over MCP: list days, read a day's timeline, search it, pull the recap, break down time by category.

What your agents can ask

  • get_timeline — everything you did on a given day, card by card
  • search_timeline — "when did I last touch the auth middleware?"
  • get_recap — the generated standup: highlights, tasks, blockers
  • category_breakdown — where the hours actually went
  • list_days — what's recorded, and how fresh the sync is

Self-host in five steps

There is no hosted service. You run the app on your Mac and the server on your own Vercel + Neon; one bearer token that only you hold guards the whole stack.

01Build the app. Clone the repo and build with Xcode 16+. Grant Screen Recording when onboarding asks.

git clone <repo> && open Panopticon/Panopticon.xcodeproj

02Create the database. A free Neon Postgres works; the schema is three tables in one file.

psql "$DATABASE_URL" -f mcp/sql/schema.sql

03Deploy the server. Ship the mcp/ directory to Vercel with two env vars: DATABASE_URL and a PANOPTICON_TOKEN you generate.

cd mcp && npm i && vercel deploy --prod

Or one click:

04Point the app at it. Settings → Export → Cloud sync: paste your deployment URL and token, toggle sync on. The first push backfills every recorded day.

05Connect your agents. Any MCP client works. For Claude Code:

claude mcp add --transport http panopticon https://<your-server>/mcp --header "Authorization: Bearer <token>"

Privacy

Local-first by construction: capture, analysis and storage live on your Mac; the cloud copy is a projection of it, not the source of truth. Recordings leave your machine only as captures sent to the LLM provider you configured — or never, with a local model. Rotate the token or drop the tables any time.
